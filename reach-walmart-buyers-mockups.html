Reach Walmart Buyers — UI prototype review

Six layout directions for the dedicated nwa-ads.com/ReachWalmartBuyers workflow. Each solves the same problem — show someone unfamiliar with Northwest Arkansas how NWA Ads' screens and billboards sit relative to Walmart's Home Office, retail corridor, store locations, and commute patterns — with a different map-first layout. Airbnb's search-page language (soft cards, coral accent, generous whitespace, map-plus-list split) is the shared visual base.

G · Illustrated corridor map

  • Fixed the legibility bug directly: the overview no longer places individual icons on top of the Walmart building blocks. It shows dark count-bubble clusters instead — the exact same visual pattern as the real markerClusterGroup in book/js/book-map.js (dark circle, white 3px ring, white bold count).
  • Four zoomed-in detail cards below give every face its own dedicated space in a plain flex row, so nothing can visually collide the way Strider Bikes did on top of the Supercenter block. Card 4 is specifically the pair that collided before.
  • Icon styling still matches makeIconHtml() exactly — colored circle, white glyph, 2.5px white ring, per-venue-type color from the real VENUE_COLORS object — just laid out with breathing room instead of packed onto one dense illustration.
  • 401 SE Walton keeps its ★, matching the site's real designated priority unit ("Exit 86 / SE Walton," book/js/book-map.js line 374). Inbound/outbound face assignment is still inferred from compass code and needs confirming against real traffic-facing intent.
